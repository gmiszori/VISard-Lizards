4. SUMMARY OF SCRAPING ARCHITECTURES
================================================================================

1. Direct Static HTML Scraping (Jsoup in Java):
   - Targets: Restaurant Bellavista (bellavista-ethz.ch), Restaurant Octavo (restaurant-octavo.ch), bQm (bqm.ch).
   - Tool: org.jsoup.Jsoup
   - Strategy: Connect via HTTP GET, select menu containers, extract text and price.

2. Food2050 Multi-Tenant Scraping (__NEXT_DATA__ JSON):
   - Targets: PHZH (app.food2050.ch/o/zfv-phzh), Mensa Molki & Bistro Tonino (ZHdK / ZHAW Toni-Areal), UZH Oerlikon, UZH Tierspital.
   - Strategy: Fetch the page HTML, extract <script id="__NEXT_DATA__" type="application/json">, parse the JSON tree with Jackson (ObjectMapper). This yields clean structured meals with zero DOM parsing errors.

3. UZH Plaene Aggregator:
   - Targets: All remaining UZH locations (BIM11, Cityport, UniTurm, The YARD, Raemi 74, Botanischer Garten).
   - Strategy: Scrape https://www.plaene.uzh.ch/ which acts as the official master directory for all UZH food services.
