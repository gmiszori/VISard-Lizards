# BACKEND TO FRONTEND INTEGRATION CONTRACT & STATUS
Updated at: 2026-10-10

## 1. Backend Status
- Backend Server: Spring Boot on http://localhost:8080
- CORS: Enabled for all origins ("*") on all endpoints
- Database: H2 In-Memory database initialized at `jdbc:h2:mem:visarddb` (Console at http://localhost:8080/h2-console, user: `sa`, password: empty)
- Cache: Caffeine In-Memory Cache enabled with automatic TTL (10 min) and cache eviction on writes/updates.

---

## 2. API Endpoints

### A. Data / Cache Records API (`/api/data`)

#### 1. Fetch All Records
- **Endpoint**: `GET http://localhost:8080/api/data`
- **Response**: Array of records `200 OK`
  ```json
  [
    {
      "id": 1,
      "dataKey": "user-pref",
      "content": "{\"theme\": \"dark\", \"sound\": true}"
    }
  ]
  ```

#### 2. Search Records (Cached by Query)
- **Endpoint**: `GET http://localhost:8080/api/data/search?q={query}`
- **Response**: Array of matching records `200 OK`
  ```json
  [
    {
      "id": 1,
      "dataKey": "user-pref",
      "content": "{\"theme\": \"dark\", \"sound\": true}"
    }
  ]
  ```

#### 3. Fetch Record by ID (Cached)
- **Endpoint**: `GET http://localhost:8080/api/data/{id}`
- **Response**: Single record `200 OK` or `404 Not Found`
  ```json
  {
    "id": 1,
    "dataKey": "user-pref",
    "content": "{\"theme\": \"dark\", \"sound\": true}"
  }
  ```

#### 4. Fetch Record by Key (Cached)
- **Endpoint**: `GET http://localhost:8080/api/data/key/{key}`
- **Response**: Single record `200 OK` or `404 Not Found`
  ```json
  {
    "id": 1,
    "dataKey": "user-pref",
    "content": "{\"theme\": \"dark\", \"sound\": true}"
  }
  ```

#### 5. Create or Update Record
- **Endpoint**: `POST http://localhost:8080/api/data`
- **Request Body**:
  ```json
  {
    "dataKey": "user-pref",
    "content": "{\"theme\": \"dark\", \"sound\": true}"
  }
  ```
- **Response**: `200 OK` with created/updated record
  ```json
  {
    "id": 1,
    "dataKey": "user-pref",
    "content": "{\"theme\": \"dark\", \"sound\": true}"
  }
  ```

#### 6. Batch Create or Update Records
- **Endpoint**: `POST http://localhost:8080/api/data/batch`
- **Request Body**:
  ```json
  [
    {
      "dataKey": "user-pref",
      "content": "{\"theme\": \"dark\"}"
    },
    {
      "dataKey": "audio-settings",
      "content": "{\"volume\": 80}"
    }
  ]
  ```
- **Response**: `200 OK` with list of created/updated records

#### 7. Update Existing Record by ID
- **Endpoint**: `PUT http://localhost:8080/api/data/{id}`
- **Request Body**:
  ```json
  {
    "content": "{\"theme\": \"light\", \"sound\": false}"
  }
  ```
- **Response**: `200 OK` or `404 Not Found`

#### 8. Delete Record by ID
- **Endpoint**: `DELETE http://localhost:8080/api/data/{id}`
- **Response**: `204 No Content`

#### 9. Delete Record by Key
- **Endpoint**: `DELETE http://localhost:8080/api/data/key/{key}`
- **Response**: `204 No Content` or `404 Not Found`

#### 10. System & Cache Health
- **Endpoint**: `GET http://localhost:8080/api/health`
- **Response**: `200 OK`
  ```json
  {
    "status": "UP",
    "timestamp": "2026-10-10T00:50:00Z",
    "activeCaches": ["data-cache"]
  }
  ```

#### 11. Cache Statistics & Metrics
- **Endpoint**: `GET http://localhost:8080/api/cache/stats`
- **Response**: `200 OK`
  ```json
  {
    "estimatedSize": 5,
    "hitCount": 42,
    "missCount": 3,
    "hitRate": 0.933,
    "evictionCount": 0,
    "loadSuccessCount": 3
  }
  ```

#### 12. Clear Cache (Manual Eviction)
- **Endpoint**: `POST http://localhost:8080/api/cache/clear`
- **Response**: `200 OK`
  ```json
  {
    "message": "Cache 'data-cache' cleared successfully"
  }
  ```
