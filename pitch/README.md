# UniEats pitch

The 5-minute pitch: an animated 3D intro (the lunch-break story), then the slides with a built-in live
demo. One self-contained file: `index.html`.

**Slogan:** Skip the queue, not lunch.

## Present

Open `index.html` in Chrome or Edge. It needs internet once for Three.js (cdnjs) and the fonts
(Google Fonts). Then press **F** for full screen.

| Key | Action |
| --- | --- |
| Click, →, Space, Enter | Next scene or slide |
| ← | Back (from the first slide back into the animation) |
| N | Speaker notes with target time, timer and pace ("on time" / "0:12 behind") |
| T | Reset the timer (it starts with the first click) |
| F | Full screen |
| Home / End | Start of the intro / last slide (the backup slide) |

"Skip intro" (top right during the animation) jumps straight to the slides.
